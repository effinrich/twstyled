# Security Policy

## Supported Versions

This project is in early release. Security fixes are made on the latest published version.

## Reporting a Vulnerability

Please report vulnerabilities privately by opening a GitHub security advisory or emailing the maintainer directly.

When reporting, include:

- A clear description of the issue
- Reproduction steps or proof of concept
- Impact assessment
- Any suggested remediation

Please do not disclose security issues publicly until a fix has been released.
